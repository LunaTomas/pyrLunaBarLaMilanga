Sistema de Gestión de Pedidos - Bar

Aplicación de escritorio desarrollada en C# para la gestión de pedidos en un entorno gastronómico.

Funcionalidades principales
Registro de pedidos
Selección de productos del menú
Interacción mediante interfaz gráfica
Gestión básica de operaciones del sistema
Tecnologías utilizadas
C#
.NET / Windows Forms
